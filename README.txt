AAROSH FOODS WEBSITE

Files:
- index.html : complete website structure
- style.css  : all responsive styling
- script.js  : mobile navigation and contact form mailto action

How to run:
1. Extract the ZIP.
2. Open the aarosh_foods_website folder.
3. Double-click index.html, or open the folder in VS Code.
4. For VS Code, use the Live Server extension and click "Go Live".

Notes:
- The design follows the one-page Aarosh Foods reference PDF.
- Food and kitchen photos load from Unsplash, so an internet connection is needed.
- The contact form opens the visitor's email app and prepares an email to enquiry@aaroshfoods.com. It does not save enquiries to a database. For a production website, connect it to a backend or form service.
- Replace the sample social links and any placeholder phone number with the company's actual details.
